Best Practices

Document durable decisions for design, code, and assistive technology support.

Design

Start with semantic structure, visible focus, sufficient contrast, and resilient reading order.

Code

Favor native HTML behavior, layer ARIA only when necessary, and keep JavaScript portable.

User experience

Name actions clearly, keep workflows short, and preserve orientation across pages and overlays.

Screen reader support

Check heading structure, announcements, and labeling with at least one major screen reader.

Keyboard-only use

Ensure every action is reachable without a pointer and that focus stays visible.

Switch and speech input

Use predictable labels and avoid gesture-only or timing-sensitive interactions.
