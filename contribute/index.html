Contribute

Contribute through small, reviewable changes grounded in semantic HTML, CSS, and vanilla JavaScript.

Before you open a change

Review existing component guidance and match the site’s semantic and naming patterns.

During implementation

Keep examples portable, keyboard accessible, and easy to test in isolation.

During review

Document the component behavior, expected keys, and ARIA decisions on the affected page.
