Status

Alerts

Alerts call attention to important state changes, warnings, or confirmations in context.

Common uses

  • Announce success, warning, or failure messages.
  • Keep critical feedback close to the triggering action.

Working demo

Review reminder

This temporary message can be dismissed with the close button.

HTML implementation

<div class="cf-demo-stack" data-dismissible>
  <div class="cf-callout cf-callout--orange cf-inline-notice" role="alert">
    <div>
      <h3 class="cf-callout__title">Review reminder</h3>
      <p class="cf-callout__body">This temporary message can be dismissed with the close button.</p>
    </div>
    <button class="cf-icon-button" type="button" data-demo-dismiss aria-label="Dismiss notice">×</button>
  </div>
</div>

JavaScript implementation

const dismissButton = document.querySelector('[data-demo-dismiss]');
dismissButton.addEventListener('click', dismissContainer);

Required ARIA

  • Use role="alert" only for urgent, automatically announced messages.
  • Prefer static text for non-urgent notices.

Keystrokes expected

  • Alerts are usually not keyboard interactive.
  • If dismissible, Tab reaches the close button and Enter or Space activates it.
