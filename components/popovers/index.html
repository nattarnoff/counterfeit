Overlay

Popovers

Popovers reveal extra contextual detail from an explicit trigger near the related control.

Common uses

  • Share optional supporting detail without redirecting the user.
  • Keep the content brief and dismissible.

Working demo

Use popovers only for brief, optional context.

HTML implementation

<div class="cf-demo-stack" data-popup-root>
  <button class="cf-button cf-button--secondary" type="button" data-popup-toggle aria-expanded="false" aria-controls="popover-panel">Show popover</button>
  <div class="cf-popup" id="popover-panel" hidden>Use popovers only for brief, optional context.</div>
</div>

JavaScript implementation

document.querySelector('[data-popup-toggle]').addEventListener('click', togglePopup);

Required ARIA

  • Use a button trigger with aria-expanded.
  • Associate the floating content with the trigger by id when appropriate.

Keystrokes expected

  • Tab reaches the trigger and any content inside the popover.
  • Enter or Space opens it.
  • Escape closes it.
