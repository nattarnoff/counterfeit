Navigation

Navs and tabs

Navs and tabs organize related destinations or panels without overwhelming the page.

Common uses

  • Use nav links for page-to-page movement and tabs for same-page panel switches.
  • Keep tab labels short and parallel.

Working demo

Nav links move between pages; tabs switch related content on the same page.
Use the arrow keys to move between these tabs.
Do not use tabs when the interaction should be a page-to-page navigation system.

HTML implementation

<div class="cf-tabset" data-tabs>
  <div class="cf-tablist" role="tablist" aria-label="Implementation views">
    <button class="cf-tab" type="button" role="tab" id="tab-guidance" aria-selected="true" aria-controls="panel-guidance">Guidance</button>
    <button class="cf-tab" type="button" role="tab" id="tab-demo" aria-selected="false" aria-controls="panel-demo" tabindex="-1">Demo</button>
    <button class="cf-tab" type="button" role="tab" id="tab-warnings" aria-selected="false" aria-controls="panel-warnings" tabindex="-1">Warnings</button>
  </div>
  <div class="cf-tab-panel" role="tabpanel" id="panel-guidance" aria-labelledby="tab-guidance">Nav links move between pages; tabs switch related content on the same page.</div>
  <div class="cf-tab-panel" role="tabpanel" id="panel-demo" aria-labelledby="tab-demo" hidden>Use the arrow keys to move between these tabs.</div>
  <div class="cf-tab-panel" role="tabpanel" id="panel-warnings" aria-labelledby="tab-warnings" hidden>Do not use tabs when the interaction should be a page-to-page navigation system.</div>
</div>

JavaScript implementation

document.querySelectorAll('[role="tab"]').forEach((tab) => {
  tab.addEventListener('keydown', handleTabKeys);
});

Required ARIA

  • For tabs, use tablist, tab, and tabpanel roles only when staying on the same page.
  • Set aria-selected and aria-controls on each tab.

Keystrokes expected

  • Tab reaches the active tab.
  • Arrow keys move between tabs.
  • Home and End jump to the first and last tab.
