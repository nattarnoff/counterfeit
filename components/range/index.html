Forms

Range

Range inputs capture approximate numeric values across a bounded interval.

Common uses

  • Choose volume, percentage, or a relative intensity value.
  • Always present the current value in text.

Working demo

Current value: 40.

HTML implementation

<div class="cf-demo-stack">
  <label class="cf-field" for="range-demo">
    <span class="cf-field__label">Contrast boost</span>
    <input class="cf-field__control cf-range" id="range-demo" type="range" min="0" max="100" value="40" data-range-input />
  </label>
  <p class="cf-form-status" data-range-status aria-live="polite">Current value: 40.</p>
</div>

JavaScript implementation

document.querySelector('[data-range-input]').addEventListener('input', announceRangeValue);

Required ARIA

  • Use the native input type="range" with a visible label.
  • Expose the current value nearby for sighted users.

Keystrokes expected

  • Tab reaches the slider.
  • Arrow keys adjust the current value.
  • Page Up, Page Down, Home, and End may also be supported by the browser.
