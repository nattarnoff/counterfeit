Status

Badge

Badge displays compact labels for status, count, or classification.

Common uses

  • Surface counts or short state labels near related content.
  • Keep supplemental text brief enough to remain scannable.

Working demo

Status: Draft

HTML implementation

<div class="cf-demo-stack">
  <p><span class="cf-badge cf-badge--yellow" data-demo-badge>Status: Draft</span></p>
  <button class="cf-button cf-button--secondary" type="button" data-cycle-badge>Cycle status</button>
</div>

JavaScript implementation

document.querySelector('[data-cycle-badge]').addEventListener('click', cycleBadgeState);

Required ARIA

  • Use plain text inside an inline semantic container.
  • Avoid relying on color alone to communicate meaning.

Keystrokes expected

  • Badges are not keyboard interactive.
  • Any nearby control that changes badge content must be keyboard accessible.
