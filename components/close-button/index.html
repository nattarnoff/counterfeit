Action

Close button

Close buttons dismiss temporary UI like alerts, dialogs, or banners.

Common uses

  • Close nonessential overlays or inline notices.
  • Provide a concise accessible name describing what will close.

Working demo

Review reminder

This temporary message can be dismissed with the close button.

HTML implementation

<div class="cf-demo-stack" data-dismissible>
  <div class="cf-callout cf-callout--orange cf-inline-notice" role="alert">
    <div>
      <h3 class="cf-callout__title">Review reminder</h3>
      <p class="cf-callout__body">This temporary message can be dismissed with the close button.</p>
    </div>
    <button class="cf-icon-button" type="button" data-demo-dismiss aria-label="Dismiss notice">×</button>
  </div>
</div>

JavaScript implementation

const dismissButton = document.querySelector('[data-demo-dismiss]');
dismissButton.addEventListener('click', dismissContainer);

Required ARIA

  • Use button with an explicit accessible name such as aria-label="Close alert".
  • Do not rely on the icon alone.

Keystrokes expected

  • Tab moves focus to the close button.
  • Enter and Space activate it.
