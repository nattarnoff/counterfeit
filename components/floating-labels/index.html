Forms

Floating labels

Floating labels keep the field label visible while saving vertical space around the control.

Common uses

  • Use only when the label remains readable in all states.
  • Keep hints and errors separate from the label.

Working demo

Start typing to see the input event update.

HTML implementation

<label class="cf-field" for="demo-name">
  <span class="cf-field__label">Display name</span>
  <span class="cf-field__hint" id="demo-name-hint">Use aria-describedby only for hint and status text.</span>
  <input class="cf-field__control" id="demo-name" name="demo-name" type="text" aria-describedby="demo-name-hint demo-name-status" />
</label>
<p class="cf-form-status" id="demo-name-status" aria-live="polite">Start typing to see the input event update.</p>

JavaScript implementation

document.querySelector('#demo-name').addEventListener('input', updatePreviewText);

Required ARIA

  • Retain a real label element bound to the input.
  • Do not replace the label with placeholder text alone.

Keystrokes expected

  • Tab moves to the input.
  • Text entry follows native input behavior.
