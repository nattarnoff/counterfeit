Forms

Floating labels

Floating labels keep the field label visible while saving vertical space around the control.

Common uses

  • Use only when the label remains readable in all states.
  • Keep hints and errors separate from the label.

Working demo

Start typing to keep the label floated.

HTML implementation

<div class="cf-floating-field">
  <input class="cf-floating-field__control" id="floating-name" name="floating-name" type="text" placeholder=" " data-floating-input aria-describedby="floating-status" />
  <label class="cf-floating-field__label" for="floating-name">Display name</label>
</div>
<p class="cf-form-status" id="floating-status" data-floating-status aria-live="polite">Start typing to keep the label floated.</p>

JavaScript implementation

document.querySelector('[data-floating-input]').addEventListener('input', updateFloatingPreview);

Required ARIA

  • Retain a real label element bound to the input.
  • Do not replace the label with placeholder text alone.

Keystrokes expected

  • Tab moves to the input.
  • Text entry follows native input behavior.
