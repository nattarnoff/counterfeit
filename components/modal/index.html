Overlay

Modal

Modal temporarily interrupts the page for a critical decision or focused task.

Common uses

  • Reserve for short flows that require attention before returning to the page.
  • Avoid stacking multiple dialogs.

Working demo

Confirm publication

Dialogs should focus attention on a short, complete task.

HTML implementation

<div class="cf-demo-stack">
  <button class="cf-button cf-button--primary" type="button" data-popup-toggle aria-expanded="false" aria-controls="modal-panel">Open modal</button>
  <div class="cf-overlay" id="modal-panel" hidden>
    <div class="cf-dialog" role="dialog" aria-modal="true" aria-labelledby="modal-title">
      <h3 id="modal-title">Confirm publication</h3>
      <p>Dialogs should focus attention on a short, complete task.</p>
      <div class="cf-demo-actions">
        <button class="cf-button cf-button--primary" type="button" data-demo-dismiss>Close</button>
      </div>
    </div>
  </div>
</div>

JavaScript implementation

document.querySelector('[data-popup-toggle]').addEventListener('click', openDialog);

Required ARIA

  • Use role="dialog" with aria-modal="true".
  • Label the dialog with aria-labelledby and optionally aria-describedby.
  • Move focus into the dialog when it opens and back to the trigger when it closes.

Keystrokes expected

  • Enter or Space opens from the trigger.
  • Escape closes the dialog.
  • Tab remains within dialog controls while it is open.
