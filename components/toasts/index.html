Feedback

Toasts

Toasts present brief, dismissible updates without fully interrupting the current task.

Common uses

  • Confirm lightweight actions like saving preferences.
  • Keep the message brief and easy to dismiss.

Working demo

Preferences saved.

HTML implementation

<div class="cf-demo-stack">
  <button class="cf-button cf-button--secondary" type="button" data-popup-toggle aria-expanded="false" aria-controls="toast-panel">Show toast</button>
  <div class="cf-toast" id="toast-panel" hidden role="status">
    <p>Preferences saved.</p>
    <button class="cf-icon-button" type="button" data-demo-dismiss aria-label="Dismiss toast">×</button>
  </div>
</div>

JavaScript implementation

document.querySelector('[data-popup-toggle]').addEventListener('click', toggleToast);

Required ARIA

  • Use role="status" for non-urgent updates or role="alert" for urgent ones.
  • Allow the toast to remain visible long enough to be read.

Keystrokes expected

  • If the toast contains a button, Tab reaches it.
  • Enter and Space activate the close action.
