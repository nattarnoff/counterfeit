Card

Cards package a small slice of related content, metadata, and actions.

Common uses

  • Present summaries that link to a fuller resource.
  • Keep related content together without overloading the page grid.

HTML implementation

<article class="cf-component-card">
  <h3 class="cf-component-card__title">Program readiness summary</h3>
  <p class="cf-component-card__description">Cards keep related content and actions together without breaking the reading order.</p>
  <button class="cf-button cf-button--secondary" type="button" data-disclosure-toggle aria-expanded="false" aria-controls="card-panel">Show detail</button>
  <div class="cf-demo-panel" id="card-panel" hidden>
    <p>Review accessibility requirements, implementation notes, and open questions in one compact block.</p>
  </div>
</article>

JavaScript implementation

document.querySelector('[data-disclosure-toggle]').addEventListener('click', toggleDisclosure);

Required ARIA

  • Use article when the card stands on its own.
  • Keep headings and links semantic rather than adding extra roles.

Keystrokes expected

  • Tab moves through any interactive content inside the card.
  • Interactive elements follow their native key behavior.
