Action

Button group

Button groups present related actions as a compact set while preserving native button behavior.

Common uses

  • Offer mutually related formatting or view controls.
  • Keep grouped actions in a shared visual container.

Working demo

Current view: List.

HTML implementation

<div class="cf-demo-stack">
  <div class="cf-button-group" role="group" aria-label="View mode">
    <button class="cf-button cf-button--secondary" type="button" data-group-button aria-pressed="true">List</button>
    <button class="cf-button cf-button--secondary" type="button" data-group-button aria-pressed="false">Grid</button>
    <button class="cf-button cf-button--secondary" type="button" data-group-button aria-pressed="false">Cards</button>
  </div>
  <p class="cf-form-status" data-group-status aria-live="polite">Current view: List.</p>
</div>

JavaScript implementation

document.querySelectorAll('[data-group-button]').forEach((button) => {
  button.addEventListener('click', updatePressedState);
});

Required ARIA

  • Use a semantic container with role="group" and an accessible name.
  • Keep each control a real button.

Keystrokes expected

  • Tab moves into the group.
  • Enter and Space activate the focused button.
