Navigation

Breadcrumb

Breadcrumbs expose the current page location within a larger site hierarchy.

Common uses

  • Support orientation in nested documentation.
  • Offer an alternate way back to higher-level sections.

Working demo

  1. Home
  2. Components
  3. Current page

HTML implementation

<nav aria-label="Breadcrumb example">
  <ol class="cf-breadcrumb">
    <li><a href="#">Home</a></li>
    <li><a href="#">Components</a></li>
    <li aria-current="page">Current page</li>
  </ol>
</nav>

JavaScript implementation

No JavaScript required for the breadcrumb itself.

Required ARIA

  • Wrap the list in a nav with an accessible name.
  • Mark the current page link or text with aria-current="page".

Keystrokes expected

  • Tab moves through each breadcrumb link.
  • Enter activates a link.
