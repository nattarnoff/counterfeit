Forms

Validation

Validation explains whether input meets the expected format or required rules.

Common uses

  • Prevent submission errors with clear inline guidance.
  • Announce problems in text, not color alone.

Working demo

Submit the form to review the validation feedback.

HTML implementation

<form class="cf-newsletter__form" data-validation-form novalidate>
  <label class="cf-field" for="validation-email">
    <span class="cf-field__label">Notification email</span>
    <input class="cf-field__control" id="validation-email" name="validation-email" type="email" required />
  </label>
  <button class="cf-button cf-button--primary" type="submit">Validate input</button>
  <p class="cf-form-status" data-validation-status aria-live="polite">Submit the form to review the validation feedback.</p>
</form>

JavaScript implementation

document.querySelector('[data-validation-form]').addEventListener('submit', validateEmailField);

Required ARIA

  • Connect error text with aria-describedby when needed.
  • Set aria-invalid="true" only when the current value is invalid.

Keystrokes expected

  • Tab moves through the form fields and submit button.
  • Enter submits the form when focus is inside a text field or on the submit button.
