Navigation

Carousel

Carousel rotates through a small set of related panels with explicit previous and next controls.

Common uses

  • Show a limited set of featured messages or slides.
  • Always provide manual controls and avoid surprise auto-rotation.

Working demo

Slide 1 of 3

Slide 1: Keep motion user-controlled.

HTML implementation

<section class="cf-carousel" data-carousel aria-label="Carousel example">
  <p class="cf-form-status" data-carousel-status aria-live="polite">Slide 1 of 3</p>
  <div class="cf-carousel__slide" data-carousel-slide>Slide 1: Keep motion user-controlled.</div>
  <div class="cf-carousel__controls">
    <button class="cf-button cf-button--secondary" type="button" data-carousel-previous>Previous</button>
    <button class="cf-button cf-button--secondary" type="button" data-carousel-next>Next</button>
  </div>
</section>

JavaScript implementation

document.querySelector('[data-carousel-next]').addEventListener('click', showNextSlide);

Required ARIA

  • Provide a label for the carousel region.
  • Keep controls as buttons and expose the current slide in text.
  • Do not hide essential information behind motion alone.

Keystrokes expected

  • Tab reaches previous and next buttons.
  • Enter and Space activate the controls.
