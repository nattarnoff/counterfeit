Navigation

List group

List groups present a concise set of related items, actions, or states.

Common uses

  • Show selectable categories or compact action lists.
  • Keep each item label distinct and short.

Working demo

Choose a list item.

HTML implementation

<div class="cf-demo-stack">
  <div class="cf-list-group" role="group" aria-label="List group example">
    <button class="cf-list-group__item" type="button" data-list-item>Guidance</button>
    <button class="cf-list-group__item" type="button" data-list-item>Examples</button>
    <button class="cf-list-group__item" type="button" data-list-item>Warnings</button>
  </div>
  <p class="cf-form-status" data-list-status aria-live="polite">Choose a list item.</p>
</div>

JavaScript implementation

document.querySelectorAll('[data-list-item]').forEach((button) => {
  button.addEventListener('click', announceSelection);
});

Required ARIA

  • Use ul or ol for plain lists.
  • If items act like navigation, keep them as links or buttons.

Keystrokes expected

  • Tab moves through interactive list items.
  • Enter activates a focused link or button.
