Navigation

Scrollspy

Scrollspy highlights which in-page section is currently active in a companion navigation list.

Common uses

  • Orient users in long single-topic documents.
  • Keep the section list concise and predictable.

Working demo

Active section: Intro.

HTML implementation

<div class="cf-scrollspy-demo">
  <nav aria-label="Section list">
    <ol class="cf-scrollspy-nav">
      <li><button class="cf-page-link" type="button" data-scrollspy-link aria-current="true">Intro</button></li>
      <li><button class="cf-page-link" type="button" data-scrollspy-link>Usage</button></li>
      <li><button class="cf-page-link" type="button" data-scrollspy-link>Warnings</button></li>
    </ol>
  </nav>
  <p class="cf-form-status" data-scrollspy-status aria-live="polite">Active section: Intro.</p>
</div>

JavaScript implementation

document.querySelectorAll('[data-scrollspy-link]').forEach((button) => {
  button.addEventListener('click', setActiveSection);
});

Required ARIA

  • Use standard anchor links inside a nav.
  • Set aria-current="true" or aria-current="location" on the active link when appropriate.

Keystrokes expected

  • Tab moves through section links.
  • Enter activates the selected anchor.
