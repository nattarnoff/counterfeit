Disclosure

Collapse

Collapse hides or shows supporting content on demand with a single trigger.

Common uses

  • Reveal advanced options or secondary details.
  • Use when content should stay in the reading order.

Working demo

Advanced options remain in the page flow and become available when needed.

HTML implementation

<div class="cf-demo-stack">
  <button class="cf-button cf-button--secondary" type="button" data-disclosure-toggle aria-expanded="false" aria-controls="collapse-panel">Show advanced options</button>
  <div class="cf-demo-panel" id="collapse-panel" hidden>
    <p>Advanced options remain in the page flow and become available when needed.</p>
  </div>
</div>

JavaScript implementation

document.querySelector('[data-disclosure-toggle]').addEventListener('click', toggleDisclosure);

Required ARIA

  • Set aria-expanded on the trigger.
  • Reference the controlled region with aria-controls.

Keystrokes expected

  • Tab reaches the toggle button.
  • Enter and Space open or close the controlled content.
