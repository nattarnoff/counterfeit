Feedback

Progress

Progress communicates completion state for a task, upload, or multi-step flow.

Common uses

  • Expose determinate task completion.
  • Pair the bar with visible text so the value is not color-only.

Working demo

Progress: 25%.

HTML implementation

<div class="cf-demo-stack">
  <div class="cf-progress-shell">
    <div class="cf-progress-bar" role="progressbar" aria-valuemin="0" aria-valuemax="100" aria-valuenow="25" data-progress-bar style="width: 25%;"></div>
  </div>
  <p class="cf-form-status" data-progress-status aria-live="polite">Progress: 25%.</p>
  <button class="cf-button cf-button--secondary" type="button" data-progress-step>Advance progress</button>
</div>

JavaScript implementation

document.querySelector('[data-progress-step]').addEventListener('click', incrementProgress);

Required ARIA

  • Use role="progressbar" with aria-valuenow, aria-valuemin, and aria-valuemax.
  • Provide a visible label.

Keystrokes expected

  • Progress indicators are usually not keyboard interactive.
  • Any control that changes the value must be keyboard accessible.
