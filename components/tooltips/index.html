Overlay

Tooltips

Tooltips expose short explanatory text on demand without replacing a visible label.

Common uses

  • Clarify an icon-only control or short status marker.
  • Keep the content short enough to read quickly.

Working demo

Keep tooltip text brief and supplemental.

HTML implementation

<div class="cf-demo-stack" data-popup-root>
  <button class="cf-button cf-button--secondary" type="button" data-popup-toggle aria-expanded="false" aria-controls="tooltip-panel">Help</button>
  <div class="cf-popup cf-tooltip" id="tooltip-panel" hidden>Keep tooltip text brief and supplemental.</div>
</div>

JavaScript implementation

document.querySelector('[data-popup-toggle]').addEventListener('click', toggleTooltip);

Required ARIA

  • Use aria-describedby to associate tooltip text with the trigger when it is visible.
  • Do not place critical instructions only in a tooltip.

Keystrokes expected

  • Tab or focus reveals the tooltip when appropriate.
  • Escape closes it when it remains open.
