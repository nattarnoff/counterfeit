Checks and radios

Checkboxes and radio buttons capture boolean and single-choice form input with durable native behavior.

Common uses

  • Use checkboxes for independent selections.
  • Use radio groups for a single required choice among options.

HTML implementation

<fieldset class="cf-fieldset">
  <legend class="cf-field__label">Release checks</legend>
  <label class="cf-check">
    <input type="checkbox" data-check-item value="Keyboard support" />
    <span>Keyboard support verified</span>
  </label>
  <label class="cf-check">
    <input type="checkbox" data-check-item value="Screen reader support" />
    <span>Screen reader support verified</span>
  </label>
  <p class="cf-form-status" data-check-status aria-live="polite">No checks selected yet.</p>
</fieldset>

JavaScript implementation

document.querySelectorAll('[data-check-item]').forEach((input) => {
  input.addEventListener('change', announceChecks);
});

Required ARIA

  • Associate every control with a visible label.
  • Wrap related radios in a fieldset with a legend.

Keystrokes expected

  • Tab moves into the fieldset.
  • Space changes the current checkbox or radio.
  • Arrow keys move within a radio group in many browsers and assistive technologies.
