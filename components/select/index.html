Forms

Select

Select fields capture one choice from a fixed set of options.

Common uses

  • Use when the option list is short enough to browse.
  • Prefer radio groups for a few always-visible options.

Working demo

Choose an option to preview the selected value.

HTML implementation

<div class="cf-demo-stack">
  <label class="cf-field" for="select-demo">
    <span class="cf-field__label">Support level</span>
    <select class="cf-field__control" id="select-demo" data-select-input>
      <option>Choose one</option>
      <option>Baseline</option>
      <option>Enhanced</option>
      <option>Advanced</option>
    </select>
  </label>
  <p class="cf-form-status" data-select-status aria-live="polite">Choose an option to preview the selected value.</p>
</div>

JavaScript implementation

document.querySelector('[data-select-input]').addEventListener('change', announceSelectedOption);

Required ARIA

  • Use the native select with a visible label.
  • Do not replace it with a custom widget unless the interaction is fully reproduced.

Keystrokes expected

  • Tab reaches the select.
  • Arrow keys move through options once the control is focused.
