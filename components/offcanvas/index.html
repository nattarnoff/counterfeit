Overlay

Offcanvas

Offcanvas slides in a supplemental panel while preserving the underlying page context.

Common uses

  • Present filters, menus, or secondary details without a full modal.
  • Keep focus management explicit.

Working demo

Filter results

Side panels work best for supplemental tasks such as filters or navigation.

HTML implementation

<div class="cf-demo-stack">
  <button class="cf-button cf-button--secondary" type="button" data-popup-toggle aria-expanded="false" aria-controls="offcanvas-panel">Open side panel</button>
  <aside class="cf-offcanvas" id="offcanvas-panel" hidden aria-labelledby="offcanvas-title">
    <div class="cf-offcanvas__header">
      <h3 id="offcanvas-title">Filter results</h3>
      <button class="cf-icon-button" type="button" data-demo-dismiss aria-label="Close side panel">×</button>
    </div>
    <p>Side panels work best for supplemental tasks such as filters or navigation.</p>
  </aside>
</div>

JavaScript implementation

document.querySelector('[data-popup-toggle]').addEventListener('click', toggleSidePanel);

Required ARIA

  • Treat the panel like a dialog when it traps attention.
  • Use aria-expanded on the trigger and an accessible label for the panel.

Keystrokes expected

  • Enter or Space opens the panel.
  • Escape closes it.
  • Tab moves through the focusable content inside the panel.
