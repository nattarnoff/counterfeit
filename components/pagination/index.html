Navigation

Pagination

Pagination splits long result sets into manageable chunks with explicit page links.

Common uses

  • Navigate search results or long indexes.
  • Make the current page obvious in text and state.

Working demo

Current page: 1.

HTML implementation

<nav aria-label="Pagination example" class="cf-demo-stack">
  <ol class="cf-pagination">
    <li><button class="cf-page-link" type="button" data-page-link aria-current="page">1</button></li>
    <li><button class="cf-page-link" type="button" data-page-link>2</button></li>
    <li><button class="cf-page-link" type="button" data-page-link>3</button></li>
  </ol>
  <p class="cf-form-status" data-page-status aria-live="polite">Current page: 1.</p>
</nav>

JavaScript implementation

document.querySelectorAll('[data-page-link]').forEach((button) => {
  button.addEventListener('click', setCurrentPage);
});

Required ARIA

  • Wrap links in nav with an accessible name.
  • Set aria-current="page" on the active page link.

Keystrokes expected

  • Tab moves through each page link.
  • Enter activates the selected page.
