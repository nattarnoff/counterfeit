Navigation

Navbar

Navbar provides consistent wayfinding across major site areas.

Common uses

  • Expose global navigation and brand context.
  • Collapse secondary links only when space demands it.

Working demo

  • Overview
  • Patterns
  • Support

HTML implementation

<div class="cf-demo-nav-surface">
  <button class="cf-button cf-button--secondary" type="button" data-disclosure-toggle aria-expanded="false" aria-controls="nav-panel">Toggle navigation</button>
  <nav class="cf-demo-panel" id="nav-panel" aria-label="Example site navigation" hidden>
    <ul class="cf-nav__list">
      <li><a href="#">Overview</a></li>
      <li><a href="#">Patterns</a></li>
      <li><a href="#">Support</a></li>
    </ul>
  </nav>
</div>

JavaScript implementation

document.querySelector('[data-disclosure-toggle]').addEventListener('click', toggleDisclosure);

Required ARIA

  • Wrap the links in nav with an accessible name.
  • Use a button with aria-expanded for any mobile toggle.

Keystrokes expected

  • Tab moves through the toggle and each link.
  • Enter and Space open the collapsed set from the toggle.
