Action

Buttons

Buttons trigger immediate actions with native button semantics and visible focus.

Common uses

  • Submit forms, launch dialogs, and trigger immediate changes.
  • Use the clearest text possible for the action outcome.

Working demo

Choose an action to preview button behavior.

HTML implementation

<div class="cf-demo-actions">
  <button class="cf-button cf-button--primary" type="button" data-demo-button="Save">Save</button>
  <button class="cf-button cf-button--secondary" type="button" data-demo-button="Cancel">Cancel</button>
</div>
<p class="cf-form-status" data-button-status aria-live="polite">Choose an action to preview button behavior.</p>

JavaScript implementation

document.querySelectorAll('[data-demo-button]').forEach((button) => {
  button.addEventListener('click', announceAction);
});

Required ARIA

  • Use the native button element.
  • Add aria-pressed only for toggle buttons that maintain state.

Keystrokes expected

  • Tab moves focus to the button.
  • Enter and Space activate the button.
