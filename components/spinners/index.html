Feedback

Spinners

Spinners indicate ongoing work when a precise completion value is not available.

Common uses

  • Show transient busy states that resolve quickly.
  • Always pair the spinner with visible loading text.

Working demo

Loading guidance…

HTML implementation

<div class="cf-demo-stack">
  <div class="cf-spinner" data-spinner aria-hidden="true"></div>
  <p class="cf-form-status" data-spinner-status aria-live="polite">Loading guidance…</p>
  <button class="cf-button cf-button--secondary" type="button" data-spinner-toggle>Resolve loading state</button>
</div>

JavaScript implementation

document.querySelector('[data-spinner-toggle]').addEventListener('click', resolveSpinner);

Required ARIA

  • Use plain text such as Loading nearby or inside an aria-live region.
  • Do not rely on animation alone to convey state.

Keystrokes expected

  • Spinners are not keyboard interactive.
  • Any related start or stop control must be keyboard accessible.
