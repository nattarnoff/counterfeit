Accordion

Accordion reveals one related section of content at a time without forcing a page change.

Common uses

  • Condense FAQs, setup steps, and supporting guidance.
  • Keep long pages scannable while preserving semantic headings.

JavaScript implementation

const trigger = document.querySelector('[data-disclosure-toggle]');
trigger.addEventListener('click', toggleDisclosure);

Required ARIA

  • Use a button inside a heading for each trigger.
  • Set aria-expanded on the trigger and aria-controls to reference the panel.
  • Hide collapsed panels with the hidden attribute.

Keystrokes expected

  • Tab reaches each accordion trigger.
  • Enter and Space toggle the current section.
