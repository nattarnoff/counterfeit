Navigation

Dropdowns

Dropdowns reveal a short action or navigation list from a trigger button.

Common uses

  • Expose secondary actions without crowding the default view.
  • Keep the list short and specific.

Working demo

Review Publish Archive

HTML implementation

<div class="cf-demo-stack cf-dropdown" data-popup-root>
  <button class="cf-button cf-button--secondary" type="button" data-popup-toggle aria-expanded="false" aria-controls="dropdown-panel">Open actions</button>
  <div class="cf-popup" id="dropdown-panel" hidden>
    <a href="#">Review</a>
    <a href="#">Publish</a>
    <a href="#">Archive</a>
  </div>
</div>

JavaScript implementation

document.querySelector('[data-popup-toggle]').addEventListener('click', togglePopup);

Required ARIA

  • Keep the trigger as a button with aria-expanded.
  • Reference the popup container with aria-controls.
  • Avoid menu roles unless the full application menu pattern is required.

Keystrokes expected

  • Tab moves to the trigger and then the revealed links.
  • Enter and Space open the dropdown from the trigger.
  • Escape closes the popup when focus is inside it.
