Placeholders

Placeholders reserve space while real content is still loading or being prepared.

Common uses

  • Prevent layout shift while async content arrives.
  • Swap to actual content as soon as it is available.

Working demo

Content is still loading.

HTML implementation

<div class="cf-demo-stack">
  <div class="cf-placeholder" data-placeholder-content aria-hidden="true"></div>
  <p class="cf-form-status" data-placeholder-status aria-live="polite">Content is still loading.</p>
  <button class="cf-button cf-button--secondary" type="button" data-placeholder-toggle>Load content</button>
</div>

JavaScript implementation

document.querySelector('[data-placeholder-toggle]').addEventListener('click', swapPlaceholder);

Required ARIA

  • Do not expose decorative placeholders as meaningful content.
  • If loading state matters, announce it separately in text.

Keystrokes expected

  • Placeholders are not keyboard interactive by themselves.
  • Any control that resolves the loading state must be keyboard accessible.
