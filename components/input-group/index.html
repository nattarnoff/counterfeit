Forms

Input group

Input groups combine a field with contextual text or an adjacent action.

Common uses

  • Prefix units, domains, or action buttons near the field.
  • Keep the extra context terse and programmatically associated.

Working demo

Enter an email address to preview the submission feedback.

HTML implementation

<form class="cf-newsletter__form" data-demo-form>
  <label class="cf-field" for="email">
    <span class="cf-field__label">Project email</span>
    <div class="cf-input-group">
      <span class="cf-input-group__prefix">@</span>
      <input class="cf-field__control" id="email" name="email" type="email" required />
      <button class="cf-button cf-button--primary" type="submit">Subscribe</button>
    </div>
  </label>
  <p class="cf-form-status" id="form-status" aria-live="polite">Enter an email address to preview the submission feedback.</p>
</form>

JavaScript implementation

document.querySelector('[data-demo-form]').addEventListener('submit', announceSubmission);

Required ARIA

  • Use visible labels even when add-ons are present.
  • If supporting text is needed, connect it with aria-describedby.

Keystrokes expected

  • Tab moves through the text field and any appended button.
  • Inputs and buttons keep native keyboard behavior.
