# Counterfeit for Figma

- Build frames on a near-black background using white primary text.
- Use red, orange, and yellow only as highlights, not as body-text replacements.
- Keep component naming aligned to Atomic Design and BEM block names.
- Preserve visible focus, 4.5:1 contrast for text, and consistent spacing tokens.
- Mirror production tokens from the CSS variable reference before introducing new styles.
